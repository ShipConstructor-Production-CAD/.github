## What Is ShipConstructor

ShipConstructor is SSI’s marine production CAD. Shipyards and marine fabricators open it when a hull already exists as a build: blocks, decks, stiffeners, pipe, HVAC. ShipConstructor production CAD is the environment. ShipConstructor marine structure is the steel or aluminum you model. ShipConstructor nest plates is how those parts meet the cutting machine the yard already runs. ShipConstructor shipyard model is the living 3D file the project controls - revisions, welds, and names that match the job.

Naval architecture suites stop at a surface and analysis. This seat continues into production. That is why a lofting hobbyist does not need it, and why a yard that still draws every bracket in 2D looks it up. Distributed systems and structure share the same model so a pipe does not punch a stiffener that already went to NC.

Use it on vessels and blocks the yard owns or was contracted to build. Keep client models inside the job. Nesting other people’s parts without a contract is not this workflow.

## Starting with ShipConstructor

Prerequisites: A licensed seat the yard administers, a hull or block you are allowed to fabricate, and shop standards for naming.

1. **Prepare:** Confirm the incoming hull or reference surfaces belong to this contract.
2. **Configure:** Set ShipConstructor production CAD units, grades, and layer standards to the yard book.
3. **Test:** Model a small panel with ShipConstructor marine structure and nest it as a dry run.
4. **Refine:** Fix collisions, then approve ShipConstructor nest plates for the burning table you run.
5. **Apply:** Grow the ShipConstructor shipyard model block by block with the production schedule.
6. **Maintain:** Issue NC only from the current revision, and lock parts that already left the nest.
